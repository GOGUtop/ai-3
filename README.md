# 落魄的作家 · AI 接力

独立 SillyTavern 扩展，前端版本 1.2.2，后端仍为 1.2.1。仅提供 AI 接力，不包含“问作者”。

## 1.2.2 字数范围与只代写 user

新增独立的“限制字数”开关，按聊天保存，默认关闭。最少字数可设为 0（仅限制上限），最少与最多相等表示固定字数。按最终发送文本中的非空白 Unicode 字符计数，含标点，不含空格和换行；这不是 API 的 tokens 配额。计数显示在生成预览下方，修改草稿时实时更新。

点击“放入输入框”或“发送到酒馆”完成交接后，自动清空生成预览和对应正则显示，不清空原话、作者要求、字数设置或 API 配置。取消替换、字数校验失败或发送按钮不可用时保留草稿。发送操作将内容交给酒馆，不代表下游模型已完成回复。

“参考来源”新增“保存参考设置”：将读取上一段、读取角色卡、读取世界书、自定义提示词开关及内容、写作预设开关及来源、单独导入的预设一起保存到酒馆账号的插件设置。保存后刷新、重新打开、换聊天或角色都继续使用，不被旧聊天里的同名开关覆盖。未点保存的修改仍可用于本次帮写；要长期保留请再次保存。原话、作者要求、生成草稿与字数范围仍按聊天隔离，不跨角色复制。API 密钥不在参考设置里；导入 JSON 的全部内容会随酒馆设置保存，请只导入可信写作预设。

普通 API 和酒馆原生预设流程均追加接力边界：只代写酒馆当前 user 的台词与自主动作，不替其他人物新增台词、动作、心理、反应或决定；上一段 AI 回复仅为上下文。三种叙述人称不改变代写对象。该边界在“人格与提示词”外层追加，不修改原人格内容、预设文件或正则。

启用限制时，普通生成清理思考标签后、原生生成执行存储正则后核对字数。超出范围或不足字数的草稿保留供编辑，显示警告，不允许放入输入框或发送；不会截断句子或自动增加收费请求。可手动修改、重新生成或调整范围。模型是否严格遵守不代演 NPC 仍受模型能力影响，请检查预览；没有用人名匹配误删用户对话。

从 1.2.1 升级只需更新本扩展前端并刷新酒馆网页，小手机、正文预设及后端无需更换。若后端早于 1.2.1，仍按下面的安装步骤更新。此版本不改变外部 API 网络故障。

## 1.2.1 故障定位

接口 404 时显示实际失败路径，并检查健康接口的运行版本，区分旧后端缺接口与当前地址根本没有加载插件。网络请求失败时显示可用的 DNS、TLS、连接或超时错误码；原生预设生成失败时读取本次转发状态，区分尚未收到本机请求与模型接口返回失败。不再一概提示重新安装。

这不是替用户自动修复外部模型服务。健康接口正常只代表插件已加载；模型列表能访问也不保证生成接口可用。需要同步更新前端与 `plugins/writer-ai-relay-server` 到 1.2.1，保留原 API 配置和酒馆端口。

## 1.2.0 人格与提示词、原生预设

“参考来源”下新增“人格与提示词”。原 Story Oracle 功能独立内置，不需要安装原插件；与小手机分别保存设置。打开后勾选顶部“启用人格与提示词”，顶部模式选择用于本次生成，原来的模式选择仍用于编辑各模式提示词。支持四个内置人格、自定义人格、AI 帮我完善、撤销、编辑、删除，以及十一种模式的原提示词编辑和重置、预设挑选及冻结快照。原模块的岗位限制由外层接力任务适配，不改写原提示词。来源和用户确认的授权见 `oracle/NOTICE.md`。

启用“使用写作预设”时，走 TavernHelper.generate 和酒馆 prepareOpenAIMessages 原生流程，保留提示词角色、顺序、深度、采样设置、宏和酒馆世界书激活逻辑，输出交给酒馆原生正则。不能用原生接口时明确报错，不退回拼接文本。要求较新的 SillyTavern 聊天补全模式和酒馆助手 TavernHelper，并支持预设正则。读取上一段、角色卡和世界书开关继续生效；关闭世界书时也排除示例注入，避免世界书示例绕过开关。

在“人格与提示词”中选中的预设冻结快照优先于外面的写作预设来源；使用该模块的挑选规则，未勾选的块不参与生成。想完整使用酒馆原预设而不经过挑选，请将人格窗口里的预设来源设为“自定义”，再用外面的“使用写作预设”。人格可单独叠加。

原生接力临时使用选定预设，编排后恢复正文设置；不切换或保存正文预设，不修改正文聊天记录。仍使用独立接力 API，服务端通过限时、单次、本机回环接口转发酒馆编排好的请求，供应商 Key 不交给浏览器。正文正在生成时不会启动原生接力，切换聊天会取消接力并丢弃跨聊天结果。

正则的文本处理和展示处理分别生效。HTML 展示在受限窗口中，不执行正则结果里的 JavaScript 或外部页面脚本。预览不是既成剧情，不自动写入 Anima。

本次必须同时更新 `server-plugin/writer-ai-relay-server` 到酒馆的 `plugins/writer-ai-relay-server`，然后完整重启。仅更新 GitHub 前端不够。

## 1.1.0 独立参考开关

读取上一段 AI 回复、读取角色卡、读取世界书、启用自定义提示词、启用写作预设五项独立控制。默认只读上一段 AI 回复；不读更早的全部聊天，思考标签不会作为正文参考。

预设来源可选酒馆当前预设、已保存预设或单独导入的聊天补全 JSON，不切换正文预设。1.2.0 起改为上述原生流程；接力最终仍只生成用户本次动作与对白，不替 NPC 完成后续整轮剧情。

世界书读取当前卡绑定、额外、全局、聊天绑定及卡内嵌条目，忽略关闭条目。数据量过大时明确报错，不默默发送截断后的资料。浮动笔尖可拖拽，位置单独保存。原有 API 接入、拉取模型和连接测试保留。

## 使用

打开悬浮笔尖按钮，填写“用户要发送的话”和可选的“给作家的要求”。人称、扩写、润色、情绪、搞笑、人前显圣、战斗、描写等选项共同生效。先生成可编辑预览，再选择放入酒馆输入框或明确发送。

“给作家的要求”会单独注入正文生成，不变成角色台词。要求按聊天保存并持续生效，清空后停止注入。生成预览本身不写成已发生的世界事件，用户发送后才成为正文输入。不会让手机后台把未确认草稿写入 Anima。

## GitHub 安装

将本目录的内容上传到一个独立 GitHub 仓库，确保 `manifest.json` 位于仓库根目录。再把该仓库地址粘贴到 SillyTavern 的“安装扩展”。目前安装包已准备好，但没有替你创建或推送远程仓库。

不要把本目录放进 phone-bridge 仓库的子目录来代替独立安装；两个扩展分开维护。

进入已安装的 AI 接力扩展目录，执行：

```sh
sh install-server.sh /home/www/SillyTavern2
```

开启 SillyTavern `config.yaml` 的 `enableServerPlugins: true`，完整重启。服务端目录是 `plugins/writer-ai-relay-server`，与手机服务端相互独立。Windows 用户可手动将 `server-plugin/writer-ai-relay-server` 复制到酒馆 `plugins` 目录后重启。

## API 设置

展开“独立 API 设置”，填写地址、Key 和模型。支持保存、拉取模型、手填模型及测试连接，使用 OpenAI-compatible Chat Completions 接口。模型列表不可用时仍可手填模型。

接力 API 不使用小手机发送或实时更新配置。密钥保存在服务器 `data/default-user/writer-ai-relay/config.json`，浏览器只收到“已保存”标志。此配置用于个人单用户酒馆，不适合互不信任的多人共享服务。

## 更新与测试

前端更新后，在扩展目录执行 `sh update.sh /home/www/SillyTavern2`，再完整重启酒馆。不要把数据目录、API Key 上传 GitHub。

```sh
npm test
npm run check
```

生成效果受所选模型影响。本次已做单元测试、模拟酒馆模块的浏览器接线测试和本机代理测试；未在你的真实酒馆和供应商 API 上端到端验证。更新后请先测试连接，再用一条带明显文风或正则替换标记的预设验收实际结果。
